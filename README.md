# BrewIon

BrewIon 是一个以咖啡信息结构化、二维码压缩编码、本地数据管理和可追溯维护为核心的开源项目集合。

当前公开模块为 **咖啡豆信息二维码编解码工具 v3.0**。它把产地、产区、庄园、处理站、豆种、处理法、烘焙、海拔、风味、日期、产季和烘焙商等信息压缩写入二维码，并提供解码、字段映射、图片中心嵌入、远程编码表同步和自定义文字扩展。

- 在线工具：<https://zjcrop.github.io/BrewIon/coffee-qr-tool/>
- 官方仓库：<https://github.com/zjcrop/BrewIon>
- 编码表目录：`coffee-qr-codebook/`
- 工具目录：`coffee-qr-tool/`
- 当前工具版本：**v3.0**
- 当前公开编码表文件：`coffee_qr_codebook_v6.json`

> 工具版本、二维码协议和编码表版本是三个不同概念。更新其中一项，不代表其他两项必须同步变更。

## 核心功能

### 1. 结构化咖啡信息编码

数据库字段使用稳定行号映射和固定宽度字段压缩。当前固定主体为32字节，包含：

| 字段 | 宽度 |
|---|---:|
| 国家 | 2字节 |
| 产区 | 2字节 |
| 庄园 / 农场 | 3字节 |
| 处理站 / 处理厂 | 3字节 |
| 豆种 | 2字节 |
| 处理法 | 2字节 |
| 烘焙信息 | 2字节 |
| 海拔 | 2字节 |
| 最多5个风味 | 10字节 |
| 烘焙日期 | 3字节 |
| 生豆产季 | 1字节 |
| **固定主体合计** | **32字节** |

### 2. CJK16烘焙商编码

- ASCII字符：通常1字节；
- CJK基本汉字和扩展A：通常2字节；
- 其他Unicode字符：使用明确转义方式保存；
- 不使用百分号编码、Base64或字段连接符。

### 3. 自定义信息

国家、产区、庄园、处理站、豆种、处理法和风味均可选择 `@自定义`。

自定义内容不会写入官方编码表，也不会改变既有数据库索引。存在自定义内容时，二维码在烘焙商字段之后写入：

```text
FF + UTF-8可读文字
```

示例：

```text
国家=实验产地
豆种=本地选育种
处理法=低压发酵
风味=青柚花香
备注=竞赛批次
```

没有自定义内容时，不写入扩展标记，保持原固定结构。

### 4. 日期与产季

- 烘焙日期允许选择：`2000-01-01` 至 `2127-09-27`；
- 日期输入框带独立日历按钮；
- 产季随烘焙年份联动，提供烘焙当年及前三年；
- 超出协议可表示范围的日期会被拒绝，不生成不可解码数据。

### 5. 二维码中心图片

- 支持图片上传和1:1裁切；
- 图片只绘制在二维码中心，不写入编码数据；
- 裁切结果保存在浏览器本地；
- 清空表单不会删除中心图片；
- 只有明确点击“移除图片”才删除本地保存。

### 6. 本地数据优先

- 编码、解码、字段映射和确定性语义解析在浏览器本地完成；
- 烘焙商和中心图片保存在浏览器本地存储；
- 远程编码表同步成功后写入本地缓存；
- 网络不可用时使用本地缓存或HTML内嵌编码表；
- 浏览器语音转文字是否联网取决于浏览器厂商实现，不属于项目可控制范围。

## 数据与协议原则

1. **可逆性优先**：二维码必须可校验、可解析，不接受只压缩但无法无损恢复的方案。
2. **索引稳定性优先**：已发布行号不得因整理、排序或删除而改变。
3. **旧码兼容性优先**：非必要情况下不改变既有字段边界。
4. **自定义信息隔离**：用户自定义内容只进入二维码文本扩展，不自动污染官方编码表。
5. **证据可追溯**：事实性数据修改必须提供来源。
6. **本地优先**：能在浏览器完成的处理不依赖后台服务。
7. **失败显式化**：校验失败、容量不足和字段错误必须明确显示，不得静默生成错误二维码。

## 使用方式

直接访问在线工具，或下载 `coffee-qr-tool/index.html` 后在现代浏览器中打开。

推荐浏览器：

- Chromium内核的Chrome、Edge；
- 支持原生日期选择器和Canvas的现代浏览器；
- 图片扫码建议使用支持原始二维码字节输出的浏览器环境。

## 贡献与维护

欢迎提交Issue、数据修订建议和Pull Request。涉及以下内容的修改，必须提供来源或可复现验证：

- 产地、产区、庄园和处理站关系；
- 豆种、处理法、别名和风味数据；
- 二维码协议、字段宽度和索引规则；
- 编解码算法、CRC和日期算法；
- 图片裁切、扫码、浏览器兼容性；
- 任何可能影响旧二维码解析的修改。
