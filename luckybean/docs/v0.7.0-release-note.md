# Lucky Bean v0.7.0 发布说明

## 界面

- 页面导航调整为“藏、拾、鉴、器”，题注为“豆藏、拾味、品鉴、器设”；
- 页面题注改为红色圆角印章样式；
- 移除顶部编码表、身份圆标、单字题注和可见版本状态；
- 表单改为无边框、虚线下划线与黑色连续背景；
- 导航与按钮改为文字主导，激活态使用浅棕黄色虚线；
- “+1”改为“添”，“老黄历”改为“诹吉”。

## 豆卡与搜索

- 删除豆卡名称输入，名称自动按“国家 · 豆种”生成；
- 产区按国家联动；
- 增加烘焙色值并自动推导烘焙度，未填写色值时允许手工选择；
- 搜索改为底部弹层，筛选选项只汇总当前豆卡实际存在的数据；
- BrewIon 远程数据与内置回退表按编码合并，避免风味标签因远程缺项消失。

## 品鉴与器设

- 品鉴记录改为“往昔……”折叠入口，默认最近5条；
- 增加历史记录页面和5–200条保存数量设置；
- 器设重组为“账户、私器、数藏、本物”；
- 技术信息、版本、开发者和社交账号仅在“本物”显示。

## 拾味

- 恢复自动分段、首段降温、萃取轨迹、风味拟合和全屏计时；
- 未配置私有 API 时使用完整本地回退模型；
- 私有 brew-profiles 仍需通过服务端 HTTPS API 调用，浏览器不直接读取私有仓库。

## Android

- 已定位旧 APK 空白页根因：WebView 资产同步目录与运行时读取路径不一致；
- 源码读取路径已修复；
- 本版本不生成或发布 APK，待 Web 端实际使用验收通过后再构建。

## 校验

- Node 单元测试：13/13；
- 静态工程检查：35个文件；
- 浏览器交互检查：15组全部通过；
- 页面异常：0；
- 控制台错误：0。
