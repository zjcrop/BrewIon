# Changelog

## 0.9.5 — 2026-08-01

- 替换为用户提供的红色/白色启动封面，红色默认、白色可选；
- 修复主题切换、顶部控制排版、豆卡和详情操作布局；
- 重构小酌字段、结果折叠标题和三种品鉴流程；
- 增加干香、分温区互动、双雷达图、整体描述和建议分；
- 器设页加入透明品牌图；
- 1.0 前统一按内部测试版在 main 维护；
- 清理旧 v094 扩展、旧 SVG/WebP 封面和 Beta 发布残留。

## 0.9.0-beta.1 — 2026-07-29

- 以 v0.8.0-beta.1 富贵盒子源码为唯一界面和数据基线，未使用外部单文件工具替换应用；
- 仅抽取独立冲煮计算工具的品种敏感度、温度、流量、萃取目标和轨迹模型；
- 修正产区与风味编码显示，过滤空标签并兼容旧 FL 编码迁移；
- 新增十阶段赏味期进度线、详情曲线当前日期点与升降趋势；
- 重构拾味布局、模型/自定义降温、详细轨迹图和下一段语音预告；
- 完善分组推荐动画、点兵点将、空白收起、品鉴布局及缺陷扣分；
- 新增滤纸/滤杯库存页面、冲煮自动扣纸和低库存红色提示。

## 0.8.0-beta.1 — 2026-07-28

### 豆藏与交互

- 豆卡缩为“国家 · 豆种 / 处理法 / 克重 / 拾”，其余信息进入详情；
- 超过6只豆子自动显示分组卡，默认按国家；进入单组后以底部“收”返回；
- 快捷区改为田字格“寻 / 添 / 撷 / 择”；
- 寻页点击遮罩关闭且取消X；撷页改为非全屏底部弹层并提供整行“退”；
- 增加个人荐榜，品鉴后得分前1/3豆卡显示金色“荐”。

### 拾味引擎

- 增加一刀流、两段式、三段式、四六法、平底46净化、五段式和30g/15秒脉冲；
- 恢复模型推荐、首段降温、研磨建议、萃取轨迹、风味拟合与专业诊断；
- 对接 Brew-Water-Calibrato v2.7 的咖啡水目标，输出Ca/Mg/HCO₃与5L粉剂换算；
- 增加JSON、TXT、Markdown方案导出；
- 计时控制改为“退 / 驻 / 进 / 终”，终止后进入消耗确认。

### 品鉴、偏好与复刻

- 增加自动得分、主观得分、分差和自然语言/语音札记；
- 标签分差形成本地偏好权重和荐榜；
- 主观得分低于自动分且存在酸尖、苦高、甜不足或干涩时生成修正方案；
- 冲煮记录保存完整方案、品鉴札记与修正关联，点击即可复刻。

### 分享

- 新增 `LB8` 压缩分享格式；豆字段沿用BrewIon代码；
- 分段采用“时间 / 克重 / 注水法两位码 / 温度”；
- 分享携带最近冲煮和品鉴记录，并提供完整编码解释文档。

### 发布边界

- 仅发布独立在线Beta，不替换v0.7.0稳定版；
- 不生成APK；私有 `brew-profiles` 精确实现不复制到公开浏览器代码。

## 0.7.0 — 2026-07-28

### 视觉与导航

- 页面改为“藏—豆藏、拾—拾味、鉴—品鉴、器—器设”；
- 页面题注使用红色圆角印章与黑色仿宋字；
- 删除顶部编码表状态、身份圆标、单字题注和版本展示；
- 底部导航改为纯文字，当前页使用白色放大文字；
- 表单取消圆角框，仅空值显示细虚线；
- 板块、豆卡、方案和设置取消描边与底色。

### 豆卡与检索

- 删除“豆卡名称”，统一显示“国家 · 豆种”；
- 增加烘焙色值，并自动推导烘焙度；
- 修复国家与产区联动；
- 搜索改为底部弹层，国家、豆种、处理法和风味仅来自现有豆卡；
- “+1”改为“添”，“老黄历”改为“诹吉”；
- 远程编码数据与内置数据合并，修复风味标签被远程不完整表覆盖的问题。

### 品鉴与器设

- 品鉴主页新增“往昔……”折叠区，默认显示最近5条；
- 增加最近记录页、最多200条显示设置，较早记录归入诹吉；
- 器设重组为账户、私器、数藏、本物；
- 账户自动生成不可逆个人 ID；
- 版本、引擎、数据源和开发者信息仅在本物中显示。

### 拾味与计时

- 恢复模型自动分段、首段低温建议和原因；
- 恢复萃取轨迹和风味拟合；
- 重做全屏计时页面，提供暂停、前后段、总时长和总剩余；
- 私有 API 不可用时使用完整离线模型，不再退化为空白或极简结果。

### 修复

- 修复改造过程中遗漏的初始化调用；
- 修复离线引擎重复导出及 API/协议函数被截断；
- 定位 Android 空白页为 APK 资产位于根目录、WebView 却读取 `www/` 子目录。

## 0.6.0 — 2026-07-27

### 重构

- 将原 441KB 单文件补丁链重建为 ES Modules、IndexedDB、独立样式和测试目录；
- 统一命名为“藏—豆藏、烹—手作、鉴—品鉴、器—器设”；
- 删除重复初始化、函数覆写和失效旧控件绑定；
- BrewIon 作为咖啡基础编码唯一主数据，增加缓存、哈希校验、原子激活和旧 `FL-*` 迁移；
- 增加私有冲煮 API 客户端、Cloudflare Worker 适配模板和本地回退引擎。

### 功能

- 新 FAB 搜索、推荐、老黄历和 +1 流程；
- 图片二维码、实时摄像头二维码、自然语言和语音录入；
- 新豆表单、必填/推荐字段、全屏风味标签编辑；
- 强制分组、豆卡详情、库存事件、冷藏和归档；
- 冲煮阶段卡、轨迹、风味拟合、语音计时和消耗确认；
- 九节点品鉴、筛选和完成后回到当前豆卡；
- 二维码/链接/HTML 分享以及明确标注的本机备注；
- PWA 缓存、导入导出和 GitHub Pages 工作流。

### 修复

- 修复启动时空 DOM 引用；
- 修复 FAB 样式写入分享模板；
- 修复分享按钮无响应及分享 Hash 页面无 `<body>`；
- 修复生成方案按钮停留在“正在计算”；
- 修复示例豆卡剩余量高于初始量；
- 修复品鉴节点可空选跳过；
- 修复相机流和图片 Object URL 未释放；
- 修复 `is-recommended` 属性/类名不一致；
- 修复版本号不一致。
