# 咖啡豆信息二维码编解码工具 v3.0

本目录包含BrewIon咖啡二维码工具的正式网页入口：

```text
coffee-qr-tool/index.html
```

在线地址：

<https://zjcrop.github.io/BrewIon/coffee-qr-tool/>

## v3.0功能

- 固定宽度数据库索引编码；
- CJK16烘焙商编码；
- CRC16-CCITT校验；
- 国家、产区、庄园、处理站、豆种、处理法和风味自定义；
- 可选UTF-8自定义文字扩展；
- 未来烘焙日期及日历按钮；
- 生豆产季随烘焙年份联动；
- 二维码中心图片上传、1:1裁切和本地保持；
- 烘焙商本地保持；
- 编码、明文映射和解码结果显示；
- 图片扫码和摄像头扫码；
- 内嵌编码表、本地缓存和远程编码表同步；
- 自由文本和语音转文字辅助录入。

## 正式编码结构

没有自定义内容：

```text
[固定主体32字节][烘焙商CJK16][CRC16原始2字节]
```

存在自定义内容：

```text
[固定主体32字节][烘焙商CJK16][FF][自定义文字UTF-8][CRC16原始2字节]
```

二维码写入原始二进制字节。页面中的 `HEX:` 内容仅用于调试、复制和人工解码，不代表二维码实际写入的是十六进制文本。

## 远程编码表

```text
https://raw.githubusercontent.com/zjcrop/BrewIon/main/coffee-qr-codebook/coffee_qr_codebook_v6.json
```

网页会：

1. 优先载入经过校验的本地缓存；
2. 尝试同步远程编码表；
3. 同步成功后更新本地缓存；
4. 网络失败时继续使用缓存或内嵌编码表。

## 本地持久化

以下设置不会因“清空表单”而删除：

- 最近使用的烘焙商；
- 已裁切的二维码中心图片。

只有明确点击“移除图片”才删除中心图片的本地保存。

浏览器清理站点数据、隐私模式结束或更换浏览器后，本地设置可能丢失。

## 部署

将本目录中的 `index.html` 上传到仓库同路径：

```text
zjcrop/BrewIon/coffee-qr-tool/index.html
```

GitHub Pages设置：

```text
Source: Deploy from a branch
Branch: main
Folder: /(root)
```

如果仓库文件已更新但Pages仍显示旧版本：

1. 在Settings → Pages中将Branch改为None并保存；
2. 再恢复为`main / (root)`并保存；
3. 重新打开在线地址确认版本号。

## 修改要求

修改 `index.html` 前必须完成：

- 保存旧版本；
- 检查页面版本号仍为v3.0或按正式发布计划变更；
- 检查二维码生成、解码和CRC；
- 检查无自定义数据的旧结构；
- 检查有自定义数据的UTF-8扩展；
- 检查图片上传、裁切和本地恢复；
- 检查日期上限；
- 检查浏览器控制台无未处理错误。

不得仅依据静态字符串检查宣布“测试通过”。涉及交互的功能必须在真实浏览器中执行。
