运行说明
  1. 文字粘贴与语义解析采用本地确定性规则引擎，不向外部大模型发送豆单文本。
  2. Chrome / Edge 的语音转文字通常需要浏览器支持，且可能调用浏览器厂商的在线语音服务，不等同于完全离线语音识别。
  3. 若 file:// 页面无法启用麦克风，可在文件目录运行 python -m http.server 8000，再通过 http://localhost:8000/ 打开。
  4. 点击“导出当前完整单文件”可保存合并后的完整网页；导出的网页保留正式编码表同步配置。
